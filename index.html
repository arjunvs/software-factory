Build a Software Factory

Tickets go in, reviewed pull requests come out. This path combines Matt Pocock’s free AI Hero guides and open-source tools, Anthropic Academy, and DeepLearning.AI short courses. Each station ends with something you build in your own practice repo. Tick items off as you go; your progress is saved in this browser.

What’s freeEvery course, guide and repo here is free to read or watch. DeepLearning.AI graded assignments and certificates need a Pro membership; the videos don’t. Anthropic Academy issues certificates for free.
What isn’tRunning an agent costs model usage. Claude Code needs a paid Claude plan or an Anthropic API key. Sandcastle also supports Codex, Copilot, Cursor, Pi and OpenCode agents, and the skills work in Copilot, Cursor and Codex too.
Left out on purposeAI Hero’s paid cohorts (including Software Factories for Real Engineers) and its paid crash courses. This path rebuilds that ground from the free material.
